# Визуализатор графа зависимостей Maven

Практическая работа № 2 по дисциплине «Конфигурационное управление», вариант 6.

Этап 1. Минимальный прототип: CLI-приложение читает параметры из
INI-файла, проверяет их и выводит в формате ключ-значение.

## Требования

- Python 3.9+ (сторонние пакеты не нужны);

## Структура репозитория

```
src/main.py          исходный код приложения
tests/test_main.py   модульные тесты (unittest)
config.ini           конфигурация по умолчанию
configs/errors/      конфигурации с ошибками для демонстрации
run.sh, run.bat      скрипты запуска приложения и тестов
```

## Настройки (INI-файл)

Все параметры находятся в секции `[settings]` и обязательны.

| Параметр       | Описание                                                                                       |
|----------------|-----------------------------------------------------------------------------------------------|
| `package_name` | Имя анализируемого пакета: `groupId:artifactId[:version]`; в тестовом режиме — `A`, `B`, ...   |
| `repository`   | URL Maven-репозитория (`https://repo1.maven.org/maven2`) или путь к файлу тестового репозитория |
| `test_mode`    | Режим работы с тестовым репозиторием: `true` / `false`                                         |
| `ascii_tree`   | Вывод зависимостей в виде ASCII-дерева: `true` / `false`                                      |

Пример:

```ini
[settings]
package_name = junit:junit:4.13.2
repository = https://repo1.maven.org/maven2
test_mode = false
ascii_tree = true
```

Обрабатываются ошибки: нет файла, некорректный INI, нет секции, нет
параметра, пустое значение, неизвестный параметр, неверное имя пакета,
неверный URL, нет файла тестового репозитория, не логическое значение
флага.
Примеры — в `configs/errors/`.

## Аргументы командной строки

| Аргумент            | Описание                                              |
|---------------------|-------------------------------------------------------|
| `-c`, `--config`    | путь к INI-файлу (по умолчанию `config.ini`)          |

## Основные функции

| Функция / класс                | Назначение                                                        |
|--------------------------------|-------------------------------------------------------------------|
| `load_config`                  | чтение и проверка всех параметров INI-файла                       |
| `get_value`, `get_flag`        | обязательные строковые и логические параметры                     |
| `validate_package`             | формат имени пакета для выбранного режима                         |
| `validate_repository`          | URL репозитория или путь к файлу тестового репозитория            |
| `print_config`                 | вывод параметров в формате ключ-значение                          |

## Сборка и запуск

Сборка не требуется.

```bash
./run.sh                                   # config.ini по умолчанию
./run.sh -c configs/errors/bad_url.ini     # пример ошибки
./run.sh test                              # модульные тесты
```

В Windows: `run.bat ...` и `run.bat test`.

## Примеры использования

`./run.sh`:

```
package_name = junit:junit:4.13.2
repository = https://repo1.maven.org/maven2
test_mode = False
ascii_tree = True
```

Ошибка в конфигурации:

```
$ ./run.sh -c configs/errors/bad_url.ini
Ошибка конфигурации: URL репозитория должен начинаться с http:// или https://, получено 'repo1.maven.org/maven2'
```
